# 分平台审计清单（按需读取对应小节）

## 巨量引擎（抖音/头条/西瓜，非电商目标：线索/APP/短剧/小程序）

- 产品形态：巨量广告（手动/自动混合），APP/短剧类常用 UBMax 自动化投放；先确认用户用的是哪种，托管程度越高可调空间越少。
- 跑量机制：oCPM 为主，计划需通过学习期（经验上约 3 天累积 ~20 个转化，以平台当期规则为准）；学习期失败计划不要反复救，复制重建往往更有效。
- 检查项：
  - 计划/素材同质化：同素材多账户多计划铺量是否触发挤压；
  - 定向：莱卡（行为兴趣）/达人相似/人群包是否过窄；自动化产品下优先给足素材而非收窄定向；
  - 素材：竖版视频为主，前 3 秒钩子；图文/横版在多数场景跑量弱；
  - 线索类：表单字段数（>5 个字段成本明显上升）、飞鱼 CRM 跟进时效（>1 小时接通率大跌）、无效线索占比与回传口径；
  - 深度转化：是否回传有效线索/付费等深度事件，只回传浅层表单会拉低质量；
  - 短剧/小程序：检查付费 ROI 出价与充值回传链路。
- 常见浪费：搜索快投未单独看搜索词；穿山甲联盟流量质量混杂未拆分；一键起量/自动扩量在成本敏感账户失控。

## 腾讯广告（微信朋友圈/视频号/公众号/小程序 + 优量汇 + QQ/腾讯系）

- 投放端：腾讯广告投放平台（ADQ）；微信流量与优量汇联盟流量务必拆开看，联盟 CTR 虚高、转化质量参差。
- 检查项：
  - 版位：朋友圈（外层文案+素材规格）、视频号（原生视频）、公众号底部、优量汇分别的成本与后端质量；
  - 定向：基础定向+行为兴趣+自定义人群（DMP），排除包是否用了（老客/已转化）；
  - 出价：oCPM/oCPC 与深度优化（如次留/付费/有效线索）是否开启；双出价阶段成本波动是否正常；
  - 微信生态链路：加企微/关注公众号/小程序留资的链路长度，每多一跳流失 30%+ 是常态；
  - 如翼人群资产（5R，R1–R5）：品牌客户看人群流转而非只看末端转化；
  - 素材：朋友圈外层文案字数限制与折叠、视频号原生感（硬广感强的素材衰退快）。
- 常见浪费：未排除已转化人群导致重复触达；联盟版位吃掉预算但后端差；同一素材长期不换。

## 快手磁力引擎（快手主站/极速版，非电商；电商用磁力金牛→见 ecommerce-ads-cn）

- 检查项：
  - 老铁生态：素材真人感/口语化/强信任背书，精致 TVC 风格普遍跑量差；
  - 定向：行为兴趣+网红粉丝定向（快手特色），达人粉丝包与素材匹配度；
  - 出价：oCPM 为主，关注"最大转化"与"成本上限"模式差异；
  - 联盟流量单独拆分；极速版与主站人群质量差异大，分端看成本；
  - 线索类：快手线索通/私信链路的响应时效。
- 常见浪费：主站与极速版混投不看分端后端；素材更新频率低于抖音节奏。

## 百度营销（搜索推广 + 信息流）

- 搜索检查项：
  - 关键词匹配方式（精确/短语/智能匹配）：智能匹配必须配搜索词报告+否词，否则泛流量吃预算；
  - 否词库：30 天未更新否词=红旗；"免费/招聘/怎么做/贴吧/图片"类词是否入库；
  - oCPC：是否进入二阶、目标成本设置与实际偏差、回传准确性；
  - 关键词结构：单元词性是否统一（一单元一主题），创意是否通配符飘红；
  - 落地页：基木鱼页面与关键词意图一致性；移动页打开速度；
  - 时段/地域：是否有凌晨低质流量、非业务地域消耗。
- 信息流检查项：意图词/兴趣定向、创意样式（大图/三图/视频）、与搜索的人群协同（搜过再推）。
- 常见浪费：智能匹配无否词；品牌词被竞品截流未监控；基木鱼表单与电话双链路只盯其一。

## 小红书聚光（效果广告：信息流+搜索）

- 检查项：
  - 投放标的：笔记种草（互动/阅读目标）vs 商销/留资（转化目标），目标选错导致"数据好看没生意"；
  - 素材=笔记：广告笔记与原生笔记的差距（硬广感→点击率低→成本高）；是否用了蒲公英报备笔记做投放（KFS 中的 F）；
  - 搜索广告：关键词买词结构（品类词/场景词/竞品词/品牌词），搜索位与信息流位成本拆开；
  - 定向：反漏斗逻辑——先核心人群再泛人群，冷启动就通投往往成本高；
  - 私信/表单链路：私信开口成本与开口率、留资组件；
  - 灵犀/AIPS：种草类客户看人群资产流转（A→I→TI→P→S），TI（深度兴趣）人群规模是种草有效性的关键中间指标；
  - 合规：医疗/功效类目资质、软文是否报备（未报备商业笔记有限流/违规风险）。
- 常见浪费：只投信息流不买搜索词（小红书搜索意图流量占比高）；用电商 ROI 口径考核种草笔记；笔记衰退后继续硬投。
